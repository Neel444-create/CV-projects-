# Model Notes

The workbook is intentionally lightweight and editable.

## Input conventions
- Yellow cells on the Route Economics sheet are scenario inputs.
- Formula cells calculate cost per kg and savings against ship and air.
- The Waterfly payload is set to 300 kg as stated in the project brief; confirm the current commercial payload specification before using externally.
- All other numeric route inputs are illustrative placeholders and must be replaced with evidence.

## Modelling cautions
- Compare equivalent door-to-door service scopes, not just line-haul rates.
- Use actual cargo delivered, not rated capacity, in cost-per-kg calculations.
- For Waterfly, do not assume every trip is fully loaded.
- Include handling, repositioning, charging, maintenance, insurance and other cost components when credible data becomes available.
- A negative savings result is valid; do not tune assumptions to force a positive outcome.
- Offshore installations are not a single fixed destination. Select a specific installation and shore base before using route distance or time.
